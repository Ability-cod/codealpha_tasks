## How to run any task

Each task folder has its own `backend` and `frontend`, and can be run independently. See the task's own README for exact steps, but in general:

```bash
cd TaskX_Name/backend
npm install
cp .env.example .env    # then fill in your local database credentials
npm run dev
```

```bash
cd TaskX_Name/frontend
npm install
npm run dev
```

**Requirements:** Node.js 18+ and MySQL (XAMPP recommended for local development).
